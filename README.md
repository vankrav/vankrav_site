# vankrav_site
Запуск локально:

1. Установите зависимости
   npm install

2. Запустите dev-сервер
   npm run dev

3. Откройте `http://localhost:3000`

Стек: Next.js App Router, React 18, JS. Секции: Header c навигацией (Проекты, Контакты, Меню с Резюме), Hero, сетка проектов, динамические страницы проекта.
